# Definition of Done

Uma tarefa pode ser marcada como concluída quando aplicável:

- requisito implementado sem divergência do PRD;
- critérios de aceite atendidos;
- regra crítica validada;
- testes escritos e passando;
- lint passando;
- typecheck passando quando aplicável;
- build passando;
- documentação atualizada;
- nenhuma credencial ou PII incluída;
- PR revisável com contexto, riscos e screenshots quando UI;
- decisões relevantes registradas em ADR;
- `HANDOFF.md` atualizado quando a sessão não encerra todo o trabalho.
